# 🛍️ SmartBuyHub - Premium Affiliate Marketing Platform

SmartBuyHub is a state-of-the-art affiliate deal converter, click tracking dashboard, and user wallet payouts ledger. It features a modern glassmorphic UI, dynamic brand retailer auto-detection, dynamic click analytics, a random visitor purchase simulator, a ₹5 instant welcome bonus, and a dynamic lifetime referral network program.

## ✨ Features

- ⚙️ **Account Settings**: Modern profile settings panel with email & phone uniqueness conflict protection.
- 🔐 **Security Manager**: Secure current password verification and password updates.
- 🔗 **Smart Link Converter**: Converts product URLs from Amazon, Flipkart, Myntra, and Ajio with brand auto-detection.
- 📈 **Dynamic Analytics Reports**: Tracks guest clicks, simulated purchase conversions, wallet commissions, and financial metrics.
- 🏆 **₹5 Welcome Bonus**: Automatically credits new users with ₹5 welcome bonus instantly upon sign-up.
- 👥 **Lifetime Refer & Earn**: Network mapping enabling users to share referral codes and earn 10% lifetime commissions from referred friends' shopping earnings.
- 💰 **Wallet Ledger Sync**: Instantly posts simulated purchase commissions as completed credit transactions directly to the payouts ledger history.

## 🛠️ Local Development Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/potturutarun-arch/Smart-Buy-Hub.git
   cd Smart-Buy-Hub
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start the Backend Express Server**:
   ```bash
   node server.js
   ```

4. **Launch Platform**:
   Access the system dashboard by navigating to `http://localhost:3000` in your web browser!
